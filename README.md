# ALINA

**Current platform:** PHP 8.5.12 | Vue 3.5 | MySQL 8.0.27 | Nginx 1.20 | Docker Compose

ALINA is a self-hosted collaboration and communication tool for corporate users and teams. It brings team conversations, video communication, publishing, discussions, and shared files together in one application.

## Core features

- **Text chat** — room-based team communication with invitations, mentions, replies, and configurable guest access.
- **Video chat** — integrated video communication for meetings and direct teamwork.
- **Posting** — create and manage richly formatted posts with the comfortable open-source WYSIWYG editor.
- **Commenting** — structured two-level discussions, paginated comment lists, and support for a pinned first-level comment.
- **Files** — attach and store files with posts and discussions, browse file lists, and view supported files directly in the application.

## Architecture

- Docker Compose deployment
- Nginx web server
- PHP backend with MVC architecture
- MySQL database
- Vue 3 SPA frontend — [ALINA_FE](https://github.com/airstarh/ALINA_FE)

## Philosophy

> Humanist, volunteer-driven, and built to help friends, partners, and teams.
> Developed by an enthusiast in free time.

# ALINA

**Текущая платформа:** PHP 8.5.12 | Vue 3.5 | MySQL 8.0.27 | Nginx 1.20 | Docker Compose

ALINA — самостоятельный инструмент для совместной работы и коммуникации корпоративных пользователей и команд. Он объединяет командное общение, видеосвязь, публикации, обсуждения и общие файлы в одном приложении.

## Основные возможности

- **Текстовый чат** — общение команды в комнатах с приглашениями, упоминаниями, ответами и настраиваемым гостевым доступом.
- **Видеочат** — встроенная видеосвязь для встреч и непосредственной совместной работы.
- **Публикации** — создание и управление форматированными публикациями с помощью удобного WYSIWYG-редактора WYSIWYG с открытым исходным кодом.
- **Комментарии** — структурированные двухуровневые обсуждения, постраничный вывод и возможность закрепить один комментарий первого уровня.
- **Файлы** — прикрепление и хранение файлов в публикациях и обсуждениях, просмотр списков и поддерживаемых файлов непосредственно в приложении.

## Архитектура

- Развёртывание с помощью Docker Compose
- Веб-сервер Nginx
- PHP-бэкенд с архитектурой MVC
- База данных MySQL
- SPA-фронтенд на Vue 3 — [ALINA_FE](https://github.com/airstarh/ALINA_FE)

# Text Chat Implementation Plan

**Goal:** Add reusable Vue chat with silent participant presence and preserve PHP compatibility.
**Architecture:** A route wrapper provides the channel to a reusable component.
A transport module owns sockets and reconnects; render components use Vue text
nodes and validated URLs. PHP ChatServer separates message history from presence.
**Tech Stack:** PHP 8.2, Ratchet/ReactPHP, Vue 3, existing Vite installation.
**Spec:** `docs/superpowers/specs/2026-09-17-text-chat-design.md`

## Global constraints

- Work inline in the user-requested checkouts; user reviews afterward.
- No commits, builds, new dependencies, or deployment.
- Tests are optional per user; use focused protocol checks and syntax verification.
